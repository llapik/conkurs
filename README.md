# CodeCraft Inc. — ИИ в разработке ПО

Интерактивный электронный образовательный ресурс (ЭОР) для конкурса
«Лучший ЭОР-2026» (номинация 3, специальность СПО 09.02.11 «Разработка и
управление программным обеспечением», квалификация «программист»).

Формат — «стажировка в ИТ-компании»: студент проходит путь от стажёра,
знакомящегося с ИИ-ассистентами кода, до специалиста, который умеет их
проверять и направлять. Три уровня допуска: **Стажёр → Джуниор → Мидл**.

## Как запустить

Модуль — статическая страница без сборки и без сервера:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000/`. Либо просто открыть `index.html`
в браузере напрямую. Интернет-соединение и API-ключи не требуются —
все «ответы ИИ» в кейсах заранее подготовлены, прогресс сохраняется
локально в браузере (`localStorage`).

## Структура

- `index.html` — разметка и модальные окна (онбординг, карта сотрудника).
- `css/style.css` — тёмная IDE-эстетика, неоновые акценты, стекломорфизм,
  адаптивная вёрстка, режим высокой контрастности.
- `js/content.js` — весь учебный контент: карточки теории, квиз,
  практические кейсы и промпт-задания.
- `js/storage.js` — работа с `localStorage` (прогресс, бейджи, настройки).
- `js/app.js` — навигация, автопроверка квиза и кода, конфетти, тайпрайтер.

## Уровни

1. **Стажёр** — 8 карточек теории про ИИ-ассистенты кода и их границы
   доверия + проверочный квиз с мгновенной обратной связью.
2. **Джуниор** — 4 практических кейса (JS и Python): в каждом «код от ИИ»
   с багом, уязвимостью или неоптимальностью, которую нужно найти и
   исправить. Проверка — юнит-тесты в браузерной песочнице или проверка
   по паттерну для Python.
3. **Мидл** — промпт-инжиниринг (сформулировать ТЗ для ИИ, чтобы получить
   безопасный код) и рефлексия «где ИИ мог ошибиться и почему». Задания
   не проверяются автоматически — ответы выгружаются в файл для
   преподавателя.
