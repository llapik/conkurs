# CodeCraft Inc. — стажировка в ИТ-компании

Интерактивная платформа-ЭОР в формате «стажировки в ИТ-компании»: студент
выбирает отдел (дисциплину) и проходит путь от стажёра, разбирающегося в
теории, до специалиста, который умеет критически проверять предложенное
решение. Общий движок — уровни допуска, бейджи, авто-проверка в браузере —
и разный контент под каждый отдел.

Изначально сделано для конкурса «Лучший ЭОР-2026» (номинация 3,
специальность СПО 09.02.11) и затем расширено под ещё один МДК на той же
платформе.

## Отделы (курсы)

1. **ИИ в разработке ПО** — специальность 09.02.11, ПК 2.2–2.5. Про
   ИИ-ассистентов кода: где им можно доверять, а где нужно перепроверять.
2. **Интерфейсы, которым доверяют** — МДК 02.01 «Проектирование и
   разработка интерфейсов пользователя» (веб-разработчики). Про UX/UI,
   доступность (a11y) и адаптивную вёрстку.

Каждый отдел устроен одинаково — три уровня допуска:

1. **Стажёр** — 8 карточек теории + проверочный квиз (8 вопросов) с
   мгновенной обратной связью.
2. **Джуниор** — 4 практических кейса: в каждом «код от ИИ» с багом,
   уязвимостью или неоптимальностью, которую нужно найти и исправить.
   Проверка — юнит-тесты в браузерной песочнице (для JS-логики) или
   проверка по паттерну (для Python/CSS/HTML-фрагментов).
3. **Мидл** — промпт-инжиниринг (сформулировать ТЗ для ИИ, чтобы получить
   качественный и безопасный результат) и рефлексия «где ИИ мог
   ошибиться и почему». Задания не проверяются автоматически — ответы
   выгружаются в файл для преподавателя.

Прогресс, бейджи и уровень допуска у каждого отдела свои и хранятся
отдельно; стартовый экран — хаб с выбором отдела.

## Как запустить

Платформа — статическая страница без сборки и без сервера:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000/`. Либо просто открыть `index.html`
в браузере напрямую. Интернет-соединение и API-ключи не требуются —
все «ответы ИИ» в кейсах заранее подготовлены, прогресс сохраняется
локально в браузере (`localStorage`).

Также настроен автодеплой на GitHub Pages при пуше в `main`
(`.github/workflows/deploy-pages.yml`).

## Структура

- `index.html` — разметка, SVG-спрайт иконок, модальные окна (онбординг,
  карта сотрудника).
- `css/style.css` — тёмная/светлая темы (+ режим высокого контраста для
  каждой), стекломорфизм, адаптивная вёрстка.
- `js/content.js` — реестр отделов `COURSES` и весь учебный контент
  (карточки теории, квиз, кейсы, промпт-задания) для каждого из них.
- `js/storage.js` — работа с `localStorage`: прогресс и бейджи отдельно
  по каждому отделу, общие настройки (тема, контраст, имя).
- `js/app.js` — навигация хаб↔отдел↔уровни, автопроверка квиза и кода,
  конфетти, тайпрайтер.

## Добавить новый отдел (курс)

Движок не завязан на конкретную дисциплину: чтобы добавить ещё один
отдел, нужно в `js/content.js` добавить его `id` в `COURSE_ORDER` и
описать объект в `COURSES` по образцу уже существующих (`meta`, `level1`,
`level2`, `level3`) — остальное (хаб, уровни допуска, бейджи, экспорт
отчёта) подхватится автоматически.
